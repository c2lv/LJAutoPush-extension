LJAutoPush

  1. 로컬 저지에 로그인한 탭에서 이 창을 엽니다.
  2. 로컬 저지 닉네임을 입력합니다.
  3. GitHub 연동을 누르고, 표시된 코드를 GitHub 화면에 붙여 넣어 승인합니다. 비공개 저장소 LJAutoPush가 만들어집니다.
  4. 전부: 체크한 결과의 내 제출을 모두 올립니다. 이미 올린 제출은 건너뜁니다.
  5. 하나: 입력한 제출 번호 하나만 올립니다. 이미 있으면 덮어씁니다.
  • 올리는 동안 이 창은 닫아도 되지만 로컬 저지 탭은 열어 두세요.
  • 버튼이 눌리지 않으면 로컬 저지 탭을 새로고침하세요.
  • 저장소를 공개로 바꾸면 풀이가 드러납니다.

아래 코드를 GitHub에 입력하면 연동됩니다.
